# RAGDOLL_ANIMATION — SVG-редактор скелетной 2D-анимации и игровых объектов

Веб-редактор 2D-анимации (без внешних зависимостей, на чистом Node.js + SVG/JS) для сборки составных персонажей («рагдолл» / скелетная структура из SVG-частей) и интерактивных игровых объектов с последующей подготовкой живых сцен-уровней для игры.

---

## Концепция и рабочий процесс

### 1. Сборка объекта или персонажа из SVG-частей
Каждый персонаж или игровой предмет хранится в отдельной папке внутри `anim/<имя_объекта>/` как набор независимых SVG-деталей:
- **Персонажи** (например, `fairy`): тень (`shadow`), тело (`body`), платье (`dress`), ноги, руки (`arm_L`, `arm_R`, сменные сгибы/рукава), голова со шляпой (`head_n_hat`, `hat_tail`), глаза (`eyes`), пряди волос и т.д.
- **Игровые объекты** (например, будильник `clock`, морковка `carrot`, цветок `flower`, крыса в клетке `rat_n_cage`, тарелка `plate`): корпус, стрелки, колокольчики, прутья клетки, хвост, лапки и т.д.

### 2. Иерархия вложенности (скелет) и Pivot Point
- Части объединяются в древовидную **иерархию слоёв и групп** (`parent`).
- Дочерние элементы наследуют трансформации родителя: например, если `голова` вложена в `тело`, то при повороте головы поворачивается только голова, а при наклоне тела оно поворачивается вместе с головой и всеми вложенными в него деталями.
- У каждой части и группы настраивается **Pivot Point** (`0..1` относительно габаритов детали) — точка вращения и центр трансформации (сустав плеча, шеи, основание стебля, ось стрелки часов), относительно которой применяются поворот, масштаб и скос.

### 3. Поза `reset` и пакет анимаций
1. Сначала выстраивается базовая поза **`reset`** — эталонное положение, масштаб, углы и видимость всех частей объекта.
2. От базовой позы создаётся **пакет анимаций** для конкретного персонажа или предмета:
   - для персонажа: `idle` / `breathe` (спокойное дыхание), `winner` (победа), `owhh` / `lose` (проигрыш / реакция) и др.;
   - для объектов: `idle` (покачивание цветка/травы), `run_cycle` и `alarm` (ход часов и звонок будильника), `drag` (реакция предмета при перетаскивании), `cage_empty` / `rat_captured` и др.
3. Все данные объекта (иерархия, pivot-точки, базовые трансформации и треки всех анимаций) сохраняются в единый пакет `anim/<имя_объекта>/settings.json`, который редактор умеет загружать, редактировать и сохранять.

### 4. План развития: Редактор сцены (уровня игры)
Следующий этап развития проекта — **Редактор сцены / уровня**:
- Формирование списка фоновых слоёв (`stage/`, например `stage/field`: небо, земля, задний и передний план травы) и размещённых на сцене персонажей и объектов из `anim/`.
- Предпросмотр всей сцены целиком с выбранными наборами анимаций: персонаж стоит на фоне поля и дышит, качается трава от лёгкого ветерка — вся сцена «дышит» и живёт.
- Настройка интерактивных игровых объектов (механики **drag-and-drop**, состояния объектов и триггеры реакций) для экспорта готовой конфигурации уровня в будущую игру.

## Интерфейс редактора объектов

- **Верхняя панель** — выбор и загрузка объекта из `anim/`, выбор/создание/переименование/удаление анимации из пакета объекта, сохранение (`Ctrl+S`), настройки.
- **Окно просмотра (Viewport)** — рабочая SVG-сцена с адаптивной сеткой:
  - панорамирование (`Пробел + ЛКМ` или средняя кнопка мыши) и масштабирование (`Ctrl + колесо мыши`, кнопки `-` / `+` / `Вписать в фрэйм`, `Ctrl+0`);
  - интерактивный **Gizmo** выделенной части/группы в двух режимах:
    - *Режим 1*: перемещение (`Move`, с `Shift` — фиксация по оси) и масштабирование за углы/грани (`Resize`), а также перетаскивание маркера **Pivot Point** без смещения визуального положения детали на сцене;
    - *Режим 2*: свободное вращение вокруг Pivot Point за углы (`Rotate`) и наклон/скос за грани (`Skew`);
  - настройка фона сцены (сетка, шахматка прозрачности, пресеты и HSV/HEX-палитра).
- **Панели инструментов и воспроизведения** — управление зумом, режимами Gizmo, записью правок в реальном времени (`Realtime`), генерацией `reset`-анимации, скоростью воспроизведения (`FPS`), навигацией по кадрам, диапазоном цикла (`loop`), ключевыми (`key`) и интерполируемыми (`tween`) кадрами, режимом «луковой кожуры» (`Onion skin`) и длительностью клипа.
- **Таймлайн (снизу)** — шкала кадров с ползунком времени (playhead) и раскрываемые дорожки свойств для каждого слоя:
  - `position` (позиция X/Y)
  - `rotation` (поворот, °)
  - `scale` (масштаб X/Y)
  - `skew` (скос X/Y, °)
  - `visible` (видимость части в кадре)
- **Правая панель**:
  - **Слои** — дерево вложенности частей и групп с поддержкой множественного выделения (`Ctrl` / `Shift`), группировки и разгруппировки, переименования (двойной клик) и смены родителя перетаскиванием (`Drag & Drop` с пересчётом мировой матрицы, чтобы деталь оставалась на месте при вложении).
  - **Свойства** — точный числовой ввод и сброс параметров `Позиция`, `Поворот`, `Масштаб`, `Скос`, `Pivot (0..1)` и видимости выбранной части.

## Быстрый старт

### Требования
- Установленный **Node.js** (внешние `npm`-пакеты не требуются — сервер использует только встроенные модули Node.js).

### Запуск на Windows
Запустите двойным кликом файл **`start.bat`**. Скрипт автоматически:
1. Запустит `server.js` на первом свободном порту в диапазоне `8000..8200`.
2. Откроет редактор в браузере по адресу `http://localhost:<порт>/`.

### Запуск из терминала (Windows / Linux / macOS)
```bash
node server.js
```
После запуска откройте адрес, выведенный в консоли (по умолчанию `http://localhost:8000/`).

### Работа напрямую из браузера через GitHub Pages + локальная папка
Редактор можно открывать прямо по ссылке GitHub Pages (`https://maguravertigo-ghost.github.io/RAGDOLL_ANIMATION/`) без запуска `server.js`:
1. Нажмите кнопку **«Настройки» (`⚙️`)** (или чип статуса в верхней панели) → **«Выбрать локальную папку…»** и укажите локальную папку проекта `RAGDOLL_ANIMATION` (либо подпапку `anim`).
2. Выбранное расположение сохраняется в **cookie** и хранилище браузера (`IndexedDB`). При обновлении страницы (`F5`) папка подхватывается автоматически, а после перезапуска браузера доступ восстанавливается в 1 клик.
3. Сохранение (**`Ctrl+S`** или кнопка дискеты) записывает `settings.json` **напрямую в вашу локальную папку на диске** (в браузерах на базе Chromium: Chrome, Edge, Яндекс.Браузер, Opera, Brave).

### Как добавить новый объект
1. Создайте папку `anim/<имя_объекта>/` и положите в неё SVG-файлы частей тела или деталей предмета.
2. Откройте редактор, нажмите кнопку **«Открыть объект»** и выберите новую папку — сервер автоматически сгенерирует стартовый `settings.json` со всеми найденными `.svg` деталями.

## HTTP API сервера (`server.js`)

| Метод | Маршрут | Описание |
| :--- | :--- | :--- |
| `GET` | `/api/objects` | Возвращает отсортированный список папок объектов из `anim/` |
| `GET` | `/api/object/:name` | Возвращает список `.svg` и содержимое `settings.json` (создаёт базовый, если файла ещё нет) |
| `POST` | `/api/object/:name/save` | Сохраняет обновлённый `settings.json` объекта на диск |
